\begin{framed}
\begin{formula}[вспомогательного угла]
$$A \sin{x} \pm B \cos{x} 
= \sqrt{\pow{A}{2} + \pow{B}{2}} \sin\br{x \pm \phi},$$

где $\phi$ называется вспомогательным углом таким, что

$$
\sin{\phi} = \frac {B}{\sqrt{\pow{A}{2} + \pow{B}{2}}},\
\cos{\phi} = \frac {A}{\sqrt{\pow{A}{2} + \pow{B}{2}}},\
\tg{\phi} = \frac {B}{A}.
$$
В частности, можно взять $\phi = \arctg\br{\dfrac {B}{A}}$.
\end{formula}
\end{framed}


Уравнение силы тока $I = I\br{t}$ будет иметь вид

$$R I\br{t} + L I\'\br{t} + \frac{1}{C} q\br{t} 
= V \sin\br{\omega t},$$
где $q\br{t}$ -- заряд конденсатора.

Взяв производную, получим
$$LC I\'\'\br{t} + RC I\br{t} + I\br{t} 
= VC\omega \cos\br{\omega t}.$$
Характеристическое уравнение имеет вид 
$LC \pow{\lambda}{2} + RC \lambda + \lambda = 0$.
Независимо от знака дискриминанта по теореме Виета
$\sub{\lambda}{1} \sub{\lambda}{2} = \dfrac {1}{LC} > 0$, но 
$\sub{\lambda}{1} + \sub{\lambda}{2} = -\dfrac{R}{L} < 0$. 
Следовательно, корни этого уравнения таковы, что
$\Re{\sub{\lambda}{1}} < 0$ и $\Re{\sub{\lambda}{2}} < 0$.
Последнее означает, что оба элемента фундаметнальной системы 
решений будут стремиться к нулю со скоростью, сопоставимой с 
$\pow {e} {\selevate{-\frac {R}{2L} t}}$
(в случае кратных корней 
$t \pow {e} {\selevate{-\frac {R}{2L} t}}$).

Итак, установившийся режим не вытекает из решения однородного 
уравнения, значит он полностью совпадает с частным решением 
неоднородного, которое в соответствии с видом правой части имеет
вид $$\sub{I}{1}\br{t} = a \sin\br{\omega t} + b \cos\br{\omega t},$$
где $a$, $b$ -- искомые коэффициенты.
\begin{align*}
    \primesub{I}{1}\br{t} 
        = a \omega \cos\br{\omega t} - b \omega \sin\br{\omega t} 
    && \primesub[2]{I}{1}\br{t} 
        = -a \pow{\omega}{2} \sin\br{\omega t} - b \pow{\omega}{2} \cos\br{\omega t}
\end{align*}
$$\tsys{
    \br{-LC\pow{\omega}{2} + 1} a - RC \omega b = 0 \\
    RC \omega a + \br{-LC\pow{\omega}{2} + 1} b = VC\omega
}$$
\begin{align*}
    \sub{\Delta}{0} = \br{-LC\pow{\omega}{2} + 1}^2 + \br{RC\omega}^2 
    && a = \frac {VR\pow{C}{2}\pow{\omega}{2}} {\sub{\Delta}{0}} 
    && b = \frac {\br{1 - LC\pow{\omega}{2}}VC\omega} {\sub{\Delta}{0}}
\end{align*}

Подставив, получаем
$$I\br{t} 
    = \frac{1}{\sub{\Delta}{0}} VC\omega 
    \br{CR\omega \sin\br{\omega t} 
        + \br{1 - LC\pow{\omega}{2}} \cos\br{\omega t}}.$$
Со вспомогательным углом 
$\phi = \arctg\br{\dfrac{LC\pow{\omega}{2} - 1}{CR\omega}}$
имеем установившийся режим
$\sub{I}{1}\br{t}$ в следующей форме:
$$\sub{I}{1} 
= \frac {VC\omega} {\sqrt{\sub{\Delta}{0}}} \sin\br{\omega t - \phi} 
= \frac {V} {\sqrt{\pow{R}{2} + \br{L\omega - \dfrac {1}{C\omega}}^2}}
    \sin\br{\omega t - \phi}.$$

Амплитуда 
$A = A\br{\omega} 
= \displaystyle \frac {V} {\sqrt{\pow{R}{2} + \br{L\omega - \dfrac {1}{C\omega}}^2}}$
силы тока тем больше, чем меньше 
$\br{L\omega - \dfrac {1}{C\omega}}^2$.
Наибольшая амплитуда достигается при
$\omega = \pm \dfrac{1}{\sqrt{LC}}$
и равна $\dfrac {V} {R}$.
