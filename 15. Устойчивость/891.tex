$\pow{x}{2}\br{t} + \pow{y}{2}\br{t} 
    = \br{\dfrac {\sub{C}{1} - \sub{C}{2} t} {1 + \pow{t}{2}}}^2
    + \br{\sub{C}{1} \pow{t}{3} \pow{e}{-t} + \sub{C}{2}\pow{e}{-t}}^2$. \\
Выберем $\sub{t}{0} = 0$ и тогда
$\pow{x}{2}\br{\sub{t}{0}} + \pow{y}{2}\br{\sub{t}{0}} = \subpow{C}{1}{2} + \subpow{C}{2}{2}$.

Исследованием функций с помощью производной нетрудно вычислить следующее:
\begin{itemize}
    \item $\tmax{t\, \ge\, 0} \br{\vbr{t}^3 \pow{e}{-t}} = \br{\dfrac {3} {e}}^3$
        достигается при $t = 3$;
    \item $\tmax{t\, \in \,{\mathbb{R}}} \dfrac {1 + \vbr{t}} {1 + \pow{t}{2}}
        = \dfrac {\sqrt{2} + 1} {2}$
        достигается при $t = \pm \br{\sqrt{2} - 1}$. \vspace{0.5em}
\end{itemize} 
Каждый из указанных максимумов меньше $2$.

Для наперёд заданного $\epsilon > 0$ положим 
$\delta\br{\epsilon} = \dfrac {\epsilon} {\sqrt{13}}$. 
Потребуем, чтобы $\subpow{C}{1}{2} + \subpow{C}{2}{2} < \pow{\delta}{2}$.
Из этого немедленно следует $\vbr{\sub{C}{1}} < \delta$ и $\vbr{\sub{C}{2}} < \delta$.
Обозначим $m = \max\br{\vbr{\sub{C}{1}}; \vbr{\sub{C}{2}}}$, тогда $m < \delta$.
Отсюда имеем \vspace{0.5em}
\begin{align*}
    \vbr{\dfrac {\sub{C}{1} - \sub{C}{2} t} {1 + \pow{t}{2}}}
        \le \dfrac {\vbr{\sub{C}{1}} + \vbr{\sub{C}{2}} \vbr{t}} {1 + \pow{t}{2}}
        \le \dfrac {m \br{1 + \vbr{t}}} {1 + \pow{t}{2}} < 2m;
    && \vbr{\sub{C}{1} \pow{t}{3} \pow{e}{-t} + \sub{C}{2}\pow{e}{-t}} < 2m + m = 3m.
\end{align*}

Наконец, 
$\pow{x}{2}\br{t} + \pow{y}{2}\br{t} 
    < \br{2m}^2 + \br{3m}^2 
    = 13\pow{m}{2} 
    < 13\pow{\delta}{2} 
    = \pow{\epsilon}{2}$,
а поэтому решение устойчиво. Кроме того, при всяких $\sub{C}{1}$ и $\sub{C}{2}$
\vspace{\lineskip}
\begin{align*}
    \tlim{\mathsmaller{t \to +\infty}} \dfrac {\sub{C}{1} - \sub{C}{2} t} {1 + \pow{t}{2}} = 0,
    && \tlim{\mathsmaller{t \to +\infty}} \br{\sub{C}{1} \pow{t}{3} \pow{e}{-t} 
        + \sub{C}{2}\pow{e}{-t}} = 0,
\end{align*}
что позволяет утверждать 
$\tlim{\mathsmaller{t \to +\infty}} \begin{pmatrix} \,x\br{t} \\ \,y\br{t}\end{pmatrix}
= \begin{pmatrix} 0 \\ 0 \end{pmatrix}$.

Вывод: решение асимптотически устойчиво.
