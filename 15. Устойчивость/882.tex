$\der{y}{x} = \dfrac {\dot{y}} {\dot{x}} = \dfrac {2y} {x}$.
$\dfrac {\pow{x}{2} \primesub{y}{x}\br{x} - 2x y\br{x}} {\pow{x}{4}} = 0$.
$\vder{}{x} \br{\dfrac {y\br{x}} {\pow{x}{2}}} = 0$.
$y = C\pow{x}{2}$. Итак, траекториями системы являются параболы, 
проходящие через начало координат фазовой плоскости.

На рисунке показаны траектории вместе с направляющими векторами, посчитанными в 
некоторых точках вдоль траекторий. По рисунку видно, что решения стремятся к началу координат,
по сути к нулевому решению $\Phi\br{t} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$,
так что решение асимптотически устойчиво, а особая точка 
$\tsys{& x = 0 \\& y = 0}$ относится к типу <<узел>>.

Докажем по определению устойчивость. Общее решение имеет вид 
$X\br{t} = \begin{pmatrix} A \pow{e}{-t} \\ B \pow{e}{-2t} \end{pmatrix}$.
Для $t \ge \sub{t}{0} = 0$
\begin{gather*}
    \br{X\br{t} - \Phi\br{t}}^2 = \pow{A}{2} \pow{e}{-2t} + \pow{B}{2} \pow{e}{-4t} \\
    \br{X\br{\sub{t}{0}} - \Phi\br{\sub{t}{0}}}^2 = \pow{A}{2} + \pow{B}{2}
\end{gather*}

Для $\epsilon > 0$ положим $\delta\br{\epsilon} = \epsilon$ и потребуем,
чтобы $A$ и $B$ были таковы, что $\pow{A}{2} + \pow{B}{2} < \pow{\delta}{2}$. 
Поскольку обе функции $\pow{e}{-2t}$ и $\pow{e}{-4t}$ убывают, 
$\pow{A}{2} \pow{e}{-2t} + \pow{B}{2} \pow{e}{-4t} 
    \le \pow{A}{2} + \pow{B}{2} < \pow{\delta}{2} = \pow{\epsilon}{2}$,
и устойчивость показана.

Асимптотическая устойчивость вытекает из того факта, что
$$\tlim{\mathsmaller{t \to +\infty}} \pow{e}{-2t} 
    = \tlim{\mathsmaller{t \to +\infty}} \pow{e}{-4t} = 0.$$
