Траектории этой системы удовлетворяют уравнению 
$\der{y}{x} = \dfrac {\dot{y}} {\dot{x}} = - \dvfrac {\sin{x}} {y \cos{x}}$.
$2y \primesub{y}{x} \br{x} = \linebreak = -2 \dvfrac {\sin{x}} {\cos{x}}$.
$\pow{y}{2}\br{x} = 2 \ln \vbr{\cos x} + C$.
Итак, траектории задаются $y\br{x} = \pm \sqrt{C + \ln \br{\cos^{2} x}}$.

Они определены только при $C > 0$ и представляют собой замкнутые кривые 
при всех таких $C$. Эти траектории вместе с направляющими векторами 
показаны на графике. Оценив рисунок, можно утверждать, что замкнутую 
траекторию можно подобрать настолько, насколько необходимо, близкой к 
началу координат фазовой плоскости, то есть к нулевому решению 
$\Phi\br{t} = \begin{pmatrix}0 \\ 0\end{pmatrix}$.

Вывод: решение устойчиво, хотя и не асимптотически. Докажем это по определению.
\vspace{1cm}

Для всякой начальной точки 
$\sub{A}{0} = \br{\x\br{\sub{t}{0}}; y\br{\sub{t}{0}}}$, где
$\vbr{x\br{\sub{t}{0}}} < \dfrac {\pi} {2}$,
можно однозначно отыскать 
$C =  \pow{y}{2}\br{\sub{t}{0}} - \ln\br{\cos^{2} x\br{\sub{t}{0}}}$,
и это означает, что через $\sub{A}{0}$ проходит единственная траектория. При $t \ge \sub{t}{0}$
точка будет оставаться на этой же траектории с неизменным $C$.
Для удобства положим $\sub{t}{0} = 0$.

Траектория $\pow{y}{2}\br{x} = 2 \ln \vbr{\cos x} + C$ определена для 
$\vbr{x} \le \arccos\br{\tpow{e} {-\frac {C} {2}}} < \dfrac {\pi} {2}$.
Обозначим за $\rho = \rho\br{t}$ расстояние от точки на траектории 
$X\br{t} = \begin{pmatrix} \,x\br{t} \\ \,y\br{t} \end{pmatrix}$ до начала координат.
$$\rho\br{t} 
    = \rho\br{\x\br{t}} 
    = \sqrt{\,\pow{x}{2}\br{t} + \pow{y}{2}\br{t}} 
    = \sqrt{\,\pow{x}{2}\br{t} + \ln\br{\cos^{2} x\br{t}} + C}
    = \sqrt{\,f\br{\x\br{t}} + C},
$$
где за $\,f\br{x}$ обозначено выражение $\,f\br{x} = \pow{x}{2} + \ln\br{\cos^{2} x}$.
Эта функция чётная и убывает для $0 \le x < \dfrac {\pi} {2}$, 
потому что для таких $x$ имеем $\f\'\br{x} = 2\br{x - \tg{x}} < 0$.
Это значит, что $\pow{x}{2} + \ln\br{\cos^{2} x} = f\br{x} \le \,f\br{0} = 0$.

Следовательно, в $x = 0$ расстояние наибольшее и равно $\sub{\rho}{\max}\br{C} = \sqrt{C}$;
наименьшее достигается в концах отрезка $x = \pm \arccos\br{\tpow {e} {-\frac {C} {2}}}$
и равно $\sub{\rho}{\min}\br{C} = \arccos\br{\tpow {e} {-\frac {C} {2}}}$.
\begin{align*}
    \vbr{X\br{t} - \Phi\br{t}} 
        = \textstyle\sqrt{\pow{x}{2}\br{t} + \pow{y}{2}\br{t}}
    && \vbr{X\br{\sub{t}{0}} - \Phi\br{\sub{t}{0}}} 
        = \textstyle\sqrt{\pow{x}{2}\br{0} + \pow{y}{2}\br{0}}
\end{align*}

Пусть теперь $\epsilon > 0$ -- произвольное и $\delta\br{\epsilon} = \arctg\br{\epsilon}$.
Потребуем также, чтобы для начальной точки $\sub{A}{0}$ выполнялось
$\sqrt{\pow{x}{2}\br{0} + \pow{y}{2}\br{0}} < \delta$.
Из этого следует
$$\delta > \textstyle\sqrt{\pow{x}{2}\br{0} + \pow{y}{2}\br{0}} 
    \ge \sub{\rho}{\min}
    = \arccos\br{\tpow {e} {-\frac {C} {2}}}.
$$

Функция $g\br{s} = \arccos\br{\tpow {e} {-\frac {s} {2}}}$ возрастает, что
позволяет решить относительно $C$ неравенство 
$\arccos\br{\tpow {e} {-\frac {C} {2}}} < \delta$
и получить $C < \ln\br{\dfrac {1}{\pow{\cos}{2} \delta}}$.

Наконец, учитывая неравенство $\ln a \le a - 1$ для всех положительных $a$,
основное тригонометрическое тождество и решение неравенства сверху, получаем при 
$t \ge \sub{t}{0} = 0$
$$\textstyle\sqrt{\pow{x}{2}\br{t} + \pow{y}{2}\br{t}}
    \le \sub{\rho}{\max}\br{C}
    = \sqrt{C}
    < \sqrt{\ln\br{\dfrac {1} {\pow{\cos}{2} \delta}}}
    \le \sqrt{ \dfrac {1}{\pow{\cos}{2} \delta} - 1 }
    = \sqrt{\pow{\tg}{2} \delta}
    = \epsilon.$$

Устойчивость доказана.
