Воспользуемся критерием Михайлова для характеристического уравнения 
$$\pow{\lambda}{4} + 3,1\pow{\lambda}{3} + 5,2 \pow{\lambda}{2} + 9,8\lambda + 5,8 = 0.$$
$$10\pow{\lambda}{4} + 31\pow{\lambda}{3} + 52 \pow{\lambda}{2} + 98\lambda + 58 = 0.$$
$p\br{\xi} = 10\pow{\xi}{2} - 52\xi + 58$,
$q\br{\eta} = -31\eta + 98$.
$\sub{\eta}{1} = \dfrac {98} {31} = 3 \dfrac {5}{31}$.
Критерий $\sub{\xi}{1} < \sub{\eta}{1} < \sub{\xi}{2}$
выполнен тогда и только тогда, когда $p\br{\sub{\eta}{1}} < 0$.
При этом квадратичная функция $p\br{\xi}$ имеет точку минимума 
$\sub{\xi}{0} = 2,6$, значит правее этой точки $p\br{\xi}$ возрастает и
$p\br{\sub{\eta}{1}} < p\br{3 \dfrac {10,5} {31}} = p\br{3,5} = -1,5$.
Следовательно, критерий Михайлова выполняется и нулевое решение устойчиво.
