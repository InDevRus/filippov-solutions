\begin{framed}
    Для угла $\phi = \ang{45}$ имеем $\tg{\beta} = \tg\br{\alpha \pm \phi} =\tg\br{\alpha \pm \ang{45}} = \dfrac {\tg\alpha \pm 1} {1 \mp \tg\alpha }$.
\end{framed}

$\pow{x}{2} + \pow{y}{2} = 2ax$.
$2a = \dfrac {\pow{y}{2} + \pow{x}{2}} {x}$.
$0 = \dfrac {\br{2yy\` + 2x}x - \pow{y}{2} - \pow{x}{2}} {\pow{x}{2}}$.
$2xyy\` + \pow{x}{2} - \pow{y}{2} = 0$.
Имеем дифференциальное уравнение $y\` = \tg\alpha = \dfrac {\pow{y}{2} - \pow{x}{2}} {2xy}$.
$\tg\beta$ будет иметь, вообще говоря, два различных значения для заданного $\tg\alpha$. Оба случая рассмотрены ниже.
\begin{align*}
    \tg\beta = \dfrac {\tg\alpha + 1} {1 - \tg\alpha}
    = \dfrac {\dfrac {\pow{y}{2} - \pow{x}{2}} {2xy} + 1} {1 - \dfrac {\pow{y}{2} - \pow{x}{2}} {2xy}}
    = \dfrac {\pow{y}{2} + 2xy - \pow{x}{2}} {-\pow{y}{2} + 2xy + \pow{x}{2}}
    = g\br{x; y\br{x}} &\\
    \tg\beta = \dfrac {\tg\alpha - 1} {1 + \tg\alpha}
    = \dfrac {\dfrac {\pow{y}{2} - \pow{x}{2}} {2xy} - 1} {1 + \dfrac {\pow{y}{2} - \pow{x}{2}} {2xy}}
    = \dfrac {\pow{y}{2} - 2xy - \pow{x}{2}} {\pow{y}{2} + 2xy - \pow{x}{2}}
    = h\br{x; y\br{x}} &
\end{align*}

Итак, имеем два уравнения изогональных траекторий вида $z\`\br{x} = g\br{x; z\br{x}}$ и $z\`\br{x} \linebreak = h\br{x; z\br{x}}$. Более конкретно, $z\` = \dfrac {\pow{z}{2} + 2xz - \pow{x}{2}} {-\pow{z}{2} + 2xz + \pow{x}{2}}$ и $z\` = \dfrac {\pow{z}{2} - 2xz - \pow{x}{2}} {\pow{z}{2} + 2xz - \pow{x}{2}}$.

\begin{remark}
    Ниже приведены решения соответствующих уравнений в виде квадратичных форм, каждая из которых в плоскости $Oxz$ задаёт окружности. Кроме того, уравнения обладают по одному дополнительному (особому) решению, каждое из которых задаёт прямую. Формально эти два решения также относятся к изогональным траекториям.
