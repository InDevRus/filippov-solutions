\begin{framed}
    Для угла $\phi = \ang{90}$ имеем $\tg{\beta} = \tg\br{\alpha \pm \phi} =\tg\br{\alpha \pm \ang{90}} = -\ctg \alpha$.
\end{framed}

$y = C\pow{x}{4}$.
$C = \dfrac {y} {\pow{x}{4}}$.
$0 = \dfrac {\pow{x}{4} y\' - 4\pow{x}{3} y} {\pow{x}{8}}$.
Итак, дифференциальное уравнение таково: $y\' = \dfrac {4y} {x}$.
$\tg\alpha = \dfrac {4y} {x}$.
$\tg\beta = -\ctg\alpha = -\dfrac {x} {4y}$. Окончательно, уравнение изогональных (ортогональных) траекторий имеет вид $z\' = -\dfrac {x} {4z}$.
$4zz\' = -x$.

\begin{remark}
    Уравнение $4zz\' = -x$ имеет общее решение $4\pow{z}{2} + \pow{x}{2} = \widetilde{C}$.
\end{remark}
