\begin{framed}
    Для угла $\phi = \ang{30}$ имеем $\tg{\beta} =
    \tg\br{\alpha \pm \phi} =
    \tg\br{\alpha \pm \ang{30}} =
    \dfrac {\sqrt{3} \tg\alpha \pm 1} {\sqrt{3} \mp \tg\alpha}$.
\end{framed}

$3\pow{x}{2} + \pow{y}{2} = C$.
$6x + 2yy\` = 0$.
$y\` = \tg\alpha = - \dfrac {3x} {y}$.

Имеем
$\tg \beta 
= \dfrac {\sqrt{3} \tg\alpha \pm 1} {\sqrt{3} \mp \tg\alpha}
= \dfrac {3\sqrt{3}x \pm y} {\sqrt{3}x \mp 3y} $.
Обозначим
$\dfrac {3\sqrt{3}x + y} {\sqrt{3}y - 3x} = g\br{x; y\br{x}}$ и 
$\dfrac {3\sqrt{3}x - y} {\sqrt{3}y + 3x} 
\linebreak = h\br{x; y\br{x}}$.
Получаются уравнения изогональных траекторий вида $z\`\br{x} = g\br{x; z\br{x}}$ и $z\`\br{x} = h\br{x; z\br{x}}$,
то есть $z\` = \dfrac {3\sqrt{3}x + z} {3x - \sqrt{3}z}$
и $z\` = \dfrac {z - 3\sqrt{3}x} {\sqrt{3}z + 3x} $.
