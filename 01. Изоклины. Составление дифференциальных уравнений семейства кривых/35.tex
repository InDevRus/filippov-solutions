$\tsys{& ax + z = b \\& \pow{y}{2} + \pow{z}{2} = \pow{b}{2}}$,
где $\tsys{& y = y\br{x} \\& z = z\br{x}}$.
Продифференцировав первое, имеем $a + z\' = 0$. \\
$\tsys{& z - xz\' = b \\& \pow{y}{2} + \pow{z}{2} = \pow{b}{2}}$.
$\pow{y}{2} + \pow{z}{2} = \br{z - xz\'}^2$.
$\pow{y}{2} + 2xzz\' - \pow{x}{2} \br{z\'}^2 = 0$.
Дифференцирование второго уравнения даёт $yy\' + zz\' = 0$.

Окончательно получаем
$\tsys{
    & \pow{y}{2} + 2xzz\' - \pow{x}{2} \br{z\'}^2 = 0
    \\& yy\' + zz\' = 0
}$.
