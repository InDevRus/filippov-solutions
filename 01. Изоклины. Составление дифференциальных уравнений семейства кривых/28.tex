$y = a\pow{x}{3} + b\pow{x}{2} + cx$.
$y\` = 3a\pow{x}{2} + 2bx + c$.
$c = y\` - 3a\pow{x}{2} - 2bx$. Подставив, получим
$y = a\pow{x}{3} + b\pow{x}{2} + xy\` - 3a\pow{x}{3} - 2b\pow{x}{2}$.
$\tsys{
    y = -2a\pow{x}{3} - b\pow{x}{2} + xy\` \\
    y\` = -6a\pow{x}{2} - 2bx + y\` + xy\`\`.}$ \\
$2y = -4a\pow{x}{3} - 2bx \cdot x + 2xy\`
= -4a\pow{x}{3} + 2xy\` - x\br{xy\`\` - 6a\pow{x}{2}} 
= 2a\pow{x}{3} + 2xy\` - \pow{x}{2}y\`\`$. \\
$\tsys{
    2y = 2a\pow{x}{3} + 2xy\` - \pow{x}{2}y\`\` \\
    2y\` = 6a\pow{x}{2} + 2y\` + 2xy\`\` - 2xy\`\` - \pow{x}{2}y\`\`\`.}$
$6a = y\`\`\`$.
$6y = \pow{x}{3} y\`\`\` + 6xy\` - 3\pow{x}{2} y\`\` = 0$.

Итак, $\pow{x}{3} y\`\`\` - 3\pow{x}{2} y\`\` + 6xy\` - 6y = 0$.
