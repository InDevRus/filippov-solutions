$\br{x - a}^2 + b\pow{y}{2} = 1$.
$2\br{x - a} + 2byy\` = 0$.
$\br{x - a}^2 = \br{-byy\`}^2 = 1 - b\pow{y}{2}$. \\
$\pow{b}{2}\pow{y}{2} \br{\y\`}^2 + b\pow{y}{2} = 1$.
$\pow{y}{2} \br{\pow{b}{2}\br{\y\`}^2 + b} = 1$.

Теперь берём производную второй раз. \vspace{\lineskip}
\begin{align*}
\der{}{x} \br{\pow{y}{2} \br{\pow{b}{2}\br{\y\`}^2 + b}}
&= \der{}{x} \br{\pow{y}{2}} \br{\pow{b}{2}\br{\y\`}^2 + b} 
    + \pow{y}{2} \cdot \der{}{x} \br{\pow{b}{2}\br{\y\`}^2 + b} \\
&= 2yy\` \br{\pow{b}{2}\br{\y\`}^2 + b} 
    + \pow{y}{2} \cdot 2\pow{b}{2}y\`y\`\` \\
&= 2yy\` \br{\pow{b}{2} \br{\y\`}^2 + b + \pow{b}{2} y y\`\`}.
\end{align*}
$\pow{b}{2} \br{\y\`}^2 + b + \pow{b}{2} y y\`\` = 0$,
а множители $y$ и $y\`$ отброшены, так как кривые, задаваемые 
условиями $y = 0$ и $y\` = 0$, не принадлежат исходным кривым.

Итак, имеем систему 
$\tsys{
    \pow{y}{2} \br{\pow{b}{2}\br{\y\`}^2 + b} = 1 \\
    \pow{b}{2} \br{\y\`}^2 + b + \pow{b}{2} y y\`\` = 0,
}$ из которой необходимо исключить $b$. \linebreak
$b\br{\br{\y\`}^2 + yy\`\`} = -1$. 
Умножив первое на $\br{\br{\y\`}^2 + yy\`\`}^2$, получим
$$\pow{y}{2} \br{
    \pow{b}{2}
    \br{\br{\y\`}^2 + yy\`\`}^2
    \br{\y\`}^2 + b \br{\br{\y\`}^2 
    + yy\`\`}^2} 
= \br{\br{\y\`}^2 + yy\`\`}^2.$$
$\pow{y}{2} \br{
    \br{\y\`}^2 - \br{\br{\y\`}^2 + yy\`\`}
} = \br{\br{\y\`}^2 + yy\`\`}^2$.
Окончательно $\br{\br{\y\`}^2 + yy\`\`}^2 + \pow{y}{3} y\`\` = 0$.
