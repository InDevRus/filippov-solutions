$\tsys{
    & \pow{x}{2} + \pow{y}{2} = \pow{z}{2} - 2bz
    \\& y = ax + b}$,
где $\tsys{& y = y\br{x} \\& z = z\br{x}}$.
Продифференцировав второе, имеем $y\' = a$. \\
$y = xy\' + b$.
$\pow{x}{2} + \pow{y}{2} = \pow{z}{2} - 2z\br{y - xy\'}$.
$\pow{x}{2} + \pow{y}{2} - \pow{z}{2} + 2yz + 2xz y\' = 0$.
Далее берём производную первого. $2b = \dfrac {\pow{z}{2} - \pow{x}{2} - \pow{y}{2}} {z}$. \vspace{1mm}
$0 = \dfrac {\br{2zz\' - 2yy\' - 2x}z - \br{\pow{z}{2} - \pow{x}{2} - \pow{y}{2}}z\'} {\pow{z}{2}}$. \\
$\pow{z}{2} z\' - 2yz y\' - 2xz + \pow{x}{2} z\' + \pow{y}{2}z\' = 0$.

Окончательно получаем
$\tsys{
    & \pow{x}{2} + \pow{y}{2} - \pow{z}{2} + 2yz + 2xz y\' = 0
    \\& \pow{z}{2} z\' - 2yz y\' - 2xz + \pow{x}{2} z\' + \pow{y}{2}z\' = 0
}$.
