$\tsys{
    x\`\` + 3y\`\` - x = 0 \\
    x\` + 3y\` - 2y = 0
}$

$3y\` = 2y - x\`$. 
$3y\`\` = 2y\` - x\`\` = x - x\`\`$,
откуда $x = 2y\`$. 
Подставив во второе, получим 
$2y\`\` + 3y\` - 2y = 0$.
$2\pow{\lambda}{2} + 3\lambda  - 2 = 0$.
$\sub{\lambda}{1} = {-2}$,
$\sub{\lambda}{2} = \dfrac {1} {2}$.

    y\br{t} = \sub{C}{1} \pow{e}{\frac {1} {2} t} + \sub{C}{2} \pow{e}{-2t};
