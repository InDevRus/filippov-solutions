$\br{\pow{x}{2} - 1} y\` + 2x\pow{y}{2} = 0$.
$\dfrac {y\`} {\pow{y}{2}} + \dvfrac {2x} {\pow{x}{2} - 1} = 0$, 
причём $y = 0$ в том числе является решением.

\begin{align*} 
\tint \dfrac {y\`} {\pow{y}{2}} \di x 
= \tint \dfrac {1} {\pow{y}{2}} d\br{\y\br{x}} 
= -\dfrac {1} {y} + C;
&& \tint \dfrac {2x} {\pow{x}{2} - 1} \di x 
= \ln\vbr{\pow{x}{2} - 1} + C.
\end{align*}

$\dfrac {1} {y} = C + \ln\vbr{\pow{x}{2} - 1}$.
$y = \dfrac {1} {C + \ln\vbr{\pow{x}{2} - 1}}$.

Итак, общее решение имеет вид 
$y = \dfrac {1} {C + \ln\vbr{\pow{x}{2} - 1}}$,
а также дополнительно $y = 0$.

Теперь найдем такое решение, что $y\br{0} = 1$. 
Решение $y = 0$ не подходит, а значит подставим $x = 0, y = 0$ 
в общее решение. 
$1 = \dfrac {1} {C}$, $C = 1$.

Искомое частное решение равняется 
$y = \dfrac {1} {1 + \ln\vbr{\pow{x}{2} - 1}}$,
причём 
$\vbr{x} < \sqrt{1 - \pow{e}{-1}}$ 
и за границы этого интервала решение продлить нельзя.

            \draw[dashed] (\A, -1) -- (\A, 5);
            
            \foreach \C in {1} {
                \addplot[Graph, thick, domain = -sqrt(1 - exp(-\C)) + 0.01 : sqrt(1 - exp(-\C)) - 0.01]

            }
        \end{axis}
    \end{tikzpicture}
    \caption*{Частное решение, удовлетворяющее $y\br{0} = 1$.}
\end{minipage}%
