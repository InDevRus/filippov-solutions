$x \der{x}{t} + t = 1$.
$x \der{x}{t} = 1 - t$.
$\tint x \der{x}{t} \di t
= \tint x \, d\br{x\br{t}}
= \dfrac {1} {2} \pow{x}{2}\br{t} + C$.

$\dfrac {1} {2} \pow{x}{2} = t - \dfrac {\pow{t}{2}} {2} + C$.
$\pow{x}{2} + \pow{t}{2} - 2t = C$.

$\pow{x}{2} + \br{t - 1}^2 = C$, где $C > 0$.
