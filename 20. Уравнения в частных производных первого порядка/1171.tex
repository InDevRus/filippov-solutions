    $y \parder{z} {x} + x \parder{z} {y} = x - y$.

    $\dvfrac {\di x} {y} = \dvfrac {\di y} {x} = \dvfrac {\di z} {x - y}$.

    \begin{enumerate}
        \item $\dvfrac {\di x} {y} = \dvfrac {\di y} {x}$; $x \di x - y \di y = 0$;
        $\pow{x}{2} + \pow{y}{2} = A$.

        \item Следующую интегрируемую комбинацию получим из первых двух дробей: \\
        $\dvfrac {\di z} {x - y} = \dfrac {\di y - \di x} {x - y}$.
        $\di z = d\br{\y - x}$.
        $z - y + x = B$.
    \end{enumerate}

    Итак, получаем в неявном виде
    $F\br{\pow{x}{2} + \pow{y}{2}; z - y + x} = 0$,
    откуда можно также выразить решение в явном виде
    $z - y + x = f\br{\pow{x}{2} + \pow{y}{2}}$;
    $z\br{x; y} = y - x + f\br{\pow{x}{2} + \pow{y}{2}}$.
