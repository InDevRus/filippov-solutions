    $xy \parder{z} {x} - \pow{x}{2} \parder{z} {y} = yz$.

    $\dfrac {\d x} {xy} = -\dfrac {\d y} {\pow{x}{2}} = \dfrac {\d z} {yz}$.
    
    \begin{enumerate}
        \item $\dfrac {\d x} {y} = - \dfrac {\d y} {x}$.
        $x \d x + y \d y = 0$.
        $\pow{x}{2} + \pow{y}{2} = A$.
        
        \item $\dfrac {\d x} {x} = \dfrac {\d z} {z}$.
        $\dfrac {z} {x} = B$.
    \end{enumerate}
    
    Итак, общее решение имеет вид
    $F\br{\pow{x}{2} + \pow{y}{2}; \dfrac {z} {x}} = 0$,
    откуда можно выразить функцию $z\br{x; y}$ в явном виде
    $z = x \cdot f\br{\pow{x}{2} + \pow{y}{2}}$.
