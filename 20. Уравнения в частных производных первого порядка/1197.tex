    $\tg x \parder{z}{x} + y \parder{z}{y} = z$.
    $\dfrac {\d x} {\tg x}
    = \dfrac {\d y} {y}
    = \dfrac {\d z} {z}$.

    Ищем первые интегралы.
    $\dvfrac {\d x} {\tg x} = \dvfrac {\d y} {y}$.
    $\ln\vbr{\sin x} = \ln\vbr{y} + A$.
    $\dvfrac {\sin x} {y} = A$.
    $\dvfrac {\d y} {y} = \dvfrac{\d z} {z}$.
    $\dvfrac {z}{y} = B$.
    Итак, общее решение имеет вид
    $F\br{\dvfrac {\sin x} {y}; \dvfrac {z} {y}} = 0$,
    либо же $z = y \,f\br{\dvfrac {\sin x} {y}}$.

    Параметризация кривой $y = x$, $z = \pow{x}{3}$ имеет вид
    $$\tsys{& x\br{t} = t \\& y\br{t} = t \\& z\br{t} = \pow{t}{3}}$$

    Подставив в первые интегралы
    $\dvfrac {\sin x} {y} = A$ и $\dvfrac {z}{y} = B$,
    получим $\dvfrac {\sin t} {t} = A$, $\pow{t}{2} = B$, так что
    $t = \pm \sqrt{B}$,
    $\sin \sqrt{B} = A \sqrt{B}$.
    $\sin \br{\sqrt{\dvfrac {z} {y}}} = \dvfrac {\sin x} {y} \sqrt{\dvfrac {z} {y}}$.
