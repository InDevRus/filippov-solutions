    $\tg x \parder{z}{x} + y \parder{z}{y} = z$.
    $\dfrac {dx} {\tg x} = \dfrac {dy} {y} = \dfrac {d
        z} {z}$.

    Ищем первые интегралы.
    $\dfrac {dx} {\tg x} = \dfrac {dy} {y}$.
    $\ln\vbr{\sin x} = \ln\vbr{y} + A$.
    $\dfrac {\sin x} {y} = A$.
    $\dfrac {dy} {y} = \dfrac{dz} {z}$.
    $\dfrac {z}{y} = B$.
    Итак, общее решение имеет вид
    $F\br{\dfrac {\sin x} {y}; \dfrac {z} {y}} = 0$, либо же $z = y f\br{\dfrac {\sin x} {y}}$.

    Параметризация кривой $y = x$, $z = \pow{x}{3}$ имеет вид
    $$\tsys{& x\br{t} = t \\& y\br{t} = t \\& z\br{t} = \pow{t}{3}}$$

    Подставив в первые интегралы
    $\dfrac {\sin x} {y} = A$ и $\dfrac {z}{y} = B$,
    получим $\dfrac {\sin t} {t} = A$, $\pow{t}{2} = B$.
    $t = \pm \sqrt{B}$,
    $\sin \sqrt{B} = A \sqrt{B}$.
    $\sin \br{\sqrt{\dfrac {z} {y}}} = \dfrac {\sin x} {y} \sqrt{\dfrac {z} {y}}$.
