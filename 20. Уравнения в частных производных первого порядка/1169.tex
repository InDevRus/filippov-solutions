    $x \parder{u} {x} + y \parder{u} {y} + z \parder{u} {z} = 0$.
    $\dfrac {dx} {x} = \dfrac {dy} {y} = \dfrac {dz} {z}$.
    \vspace{1mm}

    В данной системе первое равенство $\dfrac {dx} {x} = \dfrac {dy} {y}$ представляет собой интегрируемую комбинацию:
    $\dfrac {y dx - x dy} {\pow{y}{2}} = 0$, $\dfrac {x} {y} = A$.
    Аналогично и с $\dfrac {dy} {y} = \dfrac {dz} {z}$, откуда $\dfrac {y} {z} = B$.

    Для исходно однородного уравнения получаем $u = f\br{\dfrac {x} {y}; \dfrac {y} {z}}$.
