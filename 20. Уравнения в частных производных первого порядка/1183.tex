    $\pow{\sin}{2} x \parder{z} {x} + \tg z \parder{z} {y} = \pow{\cos}{2} z$.

    $\dvfrac {\di x} {\pow{\sin}{2} x} 
    = \dvfrac {\di y} {\vphantom{\pow{\sin}{2}}\tg{z}} 
    = \dvfrac {\di z}{\pow{\cos}{2} z}$.
        
    \begin{enumerate}
        \item $\dfrac {\di x} {\pow{\sin}{2} x} 
        = \dfrac {\di z} {\pow{\cos}{2} z}$
        -- интегрируемая комбинация.
        $\tg z + \ctg x = A$.
        
        \item $\di y = \dfrac {\tg z \di z} {\pow{\cos}{2} z} 
        = \di\br{\dfrac{1}{2} \pow{\tg}{2} z}$,
        откуда
        $2y - \pow{\tg}{2} z = B$.
    \end{enumerate}
    
    Общее решение равняется 
    $F\br{\tg z + \ctg x; 2y - \pow{\tg}{2} z} = 0$.
