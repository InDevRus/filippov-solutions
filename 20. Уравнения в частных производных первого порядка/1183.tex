    $\dvfrac {\di x} {\pow{\sin}{2} x} 
    = \dvfrac {\di y} {\vphantom{\pow{\sin}{2}}\tg{z}} 
    = \dvfrac {\di z}{\pow{\cos}{2} z}$.
        
    \begin{enumerate}
        \item $\dfrac {\di x} {x} = \di z$.
        $x = A\pow{e}{z}$;
        $A = x \pow {e}{-z}$.
        
        \item С учётом полученного выше интеграла, рассмотрим уравнение
        $\der{y}{z} = \dvfrac {xz} {y}$. \\
        $\der{y}{z} = \dvfrac {Az \pow{e}{z}} {y}$.
        $y \di y = Az \pow {e} {z} \di z$.
        $\pow{y}{2} = 2A \br{z - 1} \pow {e} {z} + B = 2x\br{z - 1} + B$.
        $\pow{y}{2} - 2x\br{z - 1} = B$.
    \end{enumerate}
    
    Общее решение равняется $F\br{x \pow{e} {-z}; \pow{y}{2} + 2x \br{1 - z}} = 0$.
