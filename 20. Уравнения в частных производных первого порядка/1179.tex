    $yz \parder{z} {x} - xz \parder{z} {y} = \tpow{e}{z}$.
    $\dfrac {dx} {yz} = \dfrac {dy} {-xz} = \tpow{e}{-z} dz$.

    $\dfrac {dx} {yz} = \dfrac {dy} {-xz}$.
    $x dx + y dy = 0$.
    $\pow{x}{2} + \pow{y}{2} = A$.

    Для отыскания второй интегрируемой комбинации запишем
    $\dfrac {dx} {y} = \dfrac {-dy} {x} = z \tpow{e} {-z} dz$
    и воспользуемся свойством дробей: \vspace{1mm}
    $z \tpow{e} {-z} dz = \dfrac {y dx - x dy} {y \cdot y + x \cdot x} = \dfrac {du} {1 + \pow{u}{2}} = d\br{\arctg u}$, где
    $u\br{x; y} = \dfrac {x} {y}$.
    Учитывая, что
    $\tint z \tpow{e} {-z} dz = -z \tpow{e} {-z} + \tint \tpow{e} {-z} dz = -\tpow{e} {-z} - z \tpow{e} {-z} + B$, получаем ещё один первый интеграл
    $\arctg\br{\dfrac {x} {y}} + \tpow{e} {-z} \br{z + 1} = B$.

    Общее решение в неявной форме:
    $$F\br{\pow{x}{2} + \pow{y}{2}; \arctg\br{\dfrac {x} {y}} + \tpow{e} {-z} \br{z + 1}} = 0.$$
    $$\tpow{e} {-z} \br{z + 1} = f\br{\pow{x}{2} + \pow{y}{2}} - \arctg\br{\dfrac {x} {y}}.$$
    $$\tpow{e} {-z - 1} \br{-z - 1} = \tpow{e}{-1} \br{\arctg\br{\dfrac {x} {y}} + f\br{\pow{x}{2} + \pow{y}{2}}}.$$
    $$-z - 1 = W\hspace{0.25mm}\br{\dfrac {1} {e} \arctg\br{\dfrac {x} {y}} + f\br{\pow{x}{2} + \pow{y}{2}}}.$$

    В явной форме получаем общее решение
    $z\br{x; y} = -1 - W\hspace{0.25mm}\br{\dfrac {1} {e} \arctg\br{\dfrac {x} {y}} + f\br{\pow{x}{2} + \pow{y}{2}}}$,
    где $W\br{t}$ -- W-функция Ламберта.
