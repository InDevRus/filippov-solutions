    $\br{z - y}^2 \parder{z} {x} + xz \parder{z} {y} = xy$.

    $\dvfrac {\di x} {\br{z - y}^2}
    = \dvfrac {\di y} {xz}
    = \dvfrac {\di z} {xy}$.
    
    \begin{enumerate}
        \item $\dvfrac {\di y} {z} = \dvfrac {\di z} {y}$.
        $\pow{y}{2} - \pow{z}{2} = A$.
        
        \item Вторую интегрируемую комбинацию получим, комбинируя дроби следующим
        образом:
        $\dvfrac {\di x} {\br{z - y}^2}
        = \dvfrac {\di y - \di z} {xz - xy}
        = \dvfrac {d\br{y - z}} {x\br{z - y}}$.
        $x \di x + \br{y - z} d\br{y - z} = 0$.
        $\pow{x}{2} + \br{y - z}^2 = B$.
    \end{enumerate}
    
    В наиболее компактной форме общее решение можно записать, как
    $$F\br{\pow{y}{2} - \pow{z}{2}; \pow{x}{2} + \br{y - z}^2} = 0.$$
