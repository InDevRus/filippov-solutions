    $\br{z - y}^2 \parder{z} {x} + xz \parder{z} {y} = xy$.
    \vspace{1mm}
    
    $\dfrac {dx} {\br{z - y}^2} = \dfrac {dy} {xz} = \dfrac {dz} {xy}$.
    
    \begin{enumerate}
        \item $\dfrac {dy} {z} = \dfrac {dz} {y}$. $\pow{y}{2} - \pow{z}{2} = A$.
        
        \item Вторую интегрируемую комбинацию получим, комбинируя дроби следующим образом:
        $\dfrac {dx} {\br{z - y}^2} = \dfrac {dy - dz} {xz - xy} = \dfrac {d\br{y - z}} {x\br{z - y}}$.
        $x dx + \br{y - z} d\br{y - z} = 0$.
        $\pow{x}{2} + \br{y - z}^2 = B$.
    \end{enumerate}
    
    В наиболее компактной форме общее решение можно записать, как
    $$F\br{\pow{y}{2} - \pow{z}{2}; \pow{x}{2} + \br{y - z}^2} = 0.$$
