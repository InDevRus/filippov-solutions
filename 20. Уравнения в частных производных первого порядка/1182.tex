    $y \vparder{z} {x} + z \vparder{z} {y} = \dfrac {y} {x}$.
    $x \parder{z} {x} + \dvfrac {xz} {y} \vparder{z} {y} = 1$,
    причём $z\br{x; y} = 0$ -- не решение.

    $\dvfrac {\di x} {x} = \dfrac {y \di y} {xz} = {\di z}$.
    
    \begin{enumerate}
        \item $\dfrac {\di x} {x} = \di z$.
        $x = A\tpow{e}{z}$;
        $A = x \tpow {e}{-z}$.
        
        \item С учётом полученного выше интеграла, рассмотрим уравнение
        $\der{y}{z} = \dvfrac {xz} {y}$. \\
        $\der{y}{z} = \dvfrac {Az \tpow{e}{z}} {y}$.
        $y \di y = Az \tpow {e} {z} \di z$.
        $\pow{y}{2} = 2A \br{z - 1} \tpow {e} {z} + B = 2x\br{z - 1} + B$.
        $\pow{y}{2} - 2x\br{z - 1} = B$.
    \end{enumerate}
    
    Общее решение равняется $F\br{x \tpow{e} {-z}; \pow{y}{2} + 2x \br{1 - z}} = 0$.
